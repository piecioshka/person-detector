# Contributing

## Requirements

- Node.js from `.nvmrc`
- [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) in `PATH` (resolves YouTube links to playable streams)

## Setup

```sh
npm install   # postinstall vendors the MediaPipe wasm runtime and downloads the model into public/vendor
npm run dev   # http://127.0.0.1:3000
```

## How it works

```mermaid
flowchart LR
  A[YouTube URL] -->|GET /api/stream| B[yt-dlp]
  B --> C[HLS playlist URL]
  C -->|GET /api/hls proxy| D[hls.js + video]
  D -->|ImageBitmap| E[Web Worker: MediaPipe EfficientDet-Lite0]
  E -->|person boxes| F[canvas overlay]
```

- A YouTube embed cannot be analyzed: the iframe is cross-origin, so its pixels are unreadable. Instead, the server asks `yt-dlp` for the stream URL (live streams are HLS only) and proxies the playlist and segments, because `googlevideo.com` sends no CORS headers.
- The proxy only fetches `https://*.googlevideo.com` and `*.youtube.com` (SSRF guard) and rewrites every URI in a playlist to go back through `/api/hls`.
- `/api/stream` and `/api/hls` are a Vite plugin (`server/stream-plugin.ts`), active in `vite dev` and `vite preview`. There is no separate backend.
- Detection: EfficientDet-Lite0 (COCO, 320x320 input) filtered to the `person` class. Wide shots are split into overlapping tiles (`computeTiles`), and duplicates from tile overlaps are merged with non-maximum suppression (`mergeBoxes`).
- One inference takes about 30 ms on an Apple M3 Pro GPU, so a 5x3 grid gives about 2-3 detections per second. Frames are only sent when the worker is idle, so they never queue up.
- `public/vendor/` is generated by `scripts/vendor-assets.mjs` and ignored by git. In dev, `server/vendor-middleware.ts` serves it before Vite's transform pipeline, because MediaPipe loads its wasm glue with a runtime `import()` that Vite would otherwise reject.

## Scripts

| Script                 | What it does                                               |
| ---------------------- | ---------------------------------------------------------- |
| `npm run dev`          | Vite dev server with the stream API                        |
| `npm run build`        | Production build to `dist/`                                |
| `npm run preview`      | Serves `dist/` with the stream API                         |
| `npm test`             | Unit tests (Vitest)                                        |
| `npm run e2e`          | End-to-end tests (Playwright) against the production build |
| `npm run typecheck`    | TypeScript check                                           |
| `npm run lint`         | ESLint                                                     |
| `npm run format:check` | Prettier check                                             |
| `npm run ci`           | Everything CI runs; also the `pre-push` hook               |

## Keyboard shortcuts

- `?` shows the cheat sheet
- `Space` pauses and resumes
- `B` toggles the boxes
- `/` focuses the URL field
